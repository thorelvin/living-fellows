Living Fellows 0.27.32: idle logistics survey

Reported behaviour
------------------
The 0.27.30 Support report shows a base-duty quartermaster standing in
logistics/storage_route_pending, with no active transfer or action reservation.
The separate movement diagnostic still names an earlier follow route. This
puts the current wait before storage selection and physical transfer ownership.
The relevant logistics/navigation source is unchanged in the 0.27.31 baseline.

Reproduction and changes
------------------------
A harness with the real planner and a deliberately expensive clock boundary
reproduces an ordinary deposit returning storage_route_pending indefinitely.
Its search slice expires before any node expansion. This is distinct from a
Loot timed action getting stuck: no transaction has started.

The route planner now prefers Performance.preciseNowMs (the native bridge's
monotonic duration clock), while retaining explicit caller-supplied test clocks.
Coarse wall-clock jumps can no longer consume a short slice when the precise
clock is available. Expiry timestamps and Support ages still use wall time.

Interaction surveys track both node expansion and the route job's progress
serial. The latter includes edge continuations and completed-path evaluation,
which can advance without expanding another node. Fifteen seconds with no
progress ends an attempt as unknown. An unfinished 90-second survey also ends
as unknown instead of silently restarting. A changing candidate set cannot
keep one ordinary deposit pending beyond 90 seconds.

Existing logistics failure handling keeps the exact item carried, cools down
the failed move, releases the worker, and permits a later retry. The existing
15-second optional loot-delivery limit remains. No transfer is invented, no
unproved route is granted, and items are not dropped to escape a planning wait.

Support reports now show the logistics item, phase, survey/progress age,
candidate count, expanded nodes and yield reason separately from movement.
Reading this evidence neither audits inventory nor starts an action.
All changes are on LF's side; zombie pathing is untouched.
