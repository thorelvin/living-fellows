Changes

Combat reads the current native WeaponCategory API when assessing the held
weapon's skill. Build 42.22 HandWeapon has isOfWeaponCategory and does not
have getCategories. The old fallback could rate a plank or wrench as having
no applicable skill, or guess SmallBlunt for a sledgehammer. Recognized skill
zero stays zero, and compatibility category lists remain a fallback.

The guarded waiting gap is bounded. After 1.2 seconds without meaningful
closing progress, a healthy lone fighter with an eligible open lane may
re-enter its weapon's desired range under guard. Normal forward clearance,
strike barriers, native recovery and attack ownership still apply. Observed
closing progress restarts the wait, and an active attack prevents re-entry.
This moves only the companion, leaving native zombie navigation untouched.

A heavy tool's nominal endurance cost magnifies actual fatigue in risk and
ordinary strike scoring. It is not treated as exhaustion merely because it
is held. The high endurance reserve, real native stamina use, encirclement,
injury and exhaustion withdrawal triggers remain in force.

Floor-finisher execution uses the same posture-aware safety check as scoring.
Two knocked-down walkers no longer veto a finishing swing or stomp through the older
aggregate count. A nearby upright attacker still closes the opening, the
victim's live grounded state is checked, and the conservative count remains
the fallback when posture-aware safety is unavailable.

When the full rear lane ends, local footwork can use the companion's ordinary
sideways steering. That heading must independently pass the same broad
three-metre geometry, terrain and floor checks. This avoids backing straight
to a field boundary while a usable lateral lane exists. Native steering
refusal, a blocked lateral lane, a tree or missing floor still rejects it.

Short blades also reserve time for the other pursuers. A strike needs more
than 1.2 seconds before another standing contact can reach the close grabbing
envelope, using observed closing speed with a conservative minimum. This
guards the native stab and recovery; it does not shorten either animation.
When those contacts are bunched, an eligible short blade can use a diagonal
turn-and-run to gain distance while changing the pursuit angle. Its native
step clearance and entire broad lane are checked separately. The ordinary
1.3-second / 2.8-metre run bound remains; refusal retains a checked rear lane.
The alternate steering proposal uses the entire three-metre clearance too.
Its ordinary short probe stays the default for other companion callers; the
longer proposal verifies the full continuous segment rather than treating
two endpoints several metres apart as one adjacent square edge.
If a nearby cluster leaves no safe short-blade stab, the companion can use
an ordinary defensive shove, at most once per 1.6 seconds. Native knockback
and knockdown can then open a strike or finisher. Wider weapons retain their
ordinary attack preference. This avoids making safe spacing an endless orbit.

Method

Same outdoor football field, real Base Watch ownership, isolated disposable
save clones and native zombies as the 0.27.29 report. Fresh companion per
case, Strength/Fitness 5, melee/Maintenance 3, standard clothing, one starting
full-condition weapon, no backup grants or mid-fight stat refills. Normal
game speed and inherited multi-hit TRUE. Only initial detection is seeded;
pursuit, collision, damage, wear and weapon breakage remain native.

The case table preserves 1..60 and appends plank 61..66, sledgehammer 67..72,
wrench 73..78 and kitchen knife 79..84. Each weapon has cases for 0..5 zombies.
Loaded-floor cleanup reads all 2,025 native square static lists back between
cases. Selected cases can be repeated in fresh-clone runs.

The baseline and earlier screens capped fights at 90 seconds. Later diagnostic
trials used 150 seconds; final observations allow 180 seconds. The recorder's
withdrawal endpoint now requires five continuous seconds and eight metres of
pull-out outside the original 26-metre radius. Earlier screens ended after
one cumulative retreat second outside that radius, which could censor brief
spacing after long kiting. All raw retreat time remains recorded. These
measurement changes preclude comparing the screen totals as success rates.
