# Living Fellows 0.17.0 - Faction Life

## Goal

Version 0.17 turns the 0.16 barricaded household into a small persistent social
simulation. It deliberately remains bounded: one life record per household,
at most three residents, twelve relationships, three generated rumors, thirty-two
resolved crises, and 128 recent events.

## Persistent state

Each household stores a deterministic primary/secondary personality blend from
Paranoid, Generous, Militarized, Desperate, Isolationist, and Resourceful. The
blend exposes caution, generosity, discipline, solidarity, and openness. Every
living pair has a Family, Friends, Partners, Strangers, or Rivals relationship
with bounded affinity, trust, and tension. The state is additive for existing
0.16 faction documents and does not require old NPC compatibility.

## Visible life

Residents receive one half-hour routine block: sleep, meal, watch, maintenance,
inventory check, organize, socialize, or read. The target is selected from the
house's already bounded interior-square list. Native visual actions own their
pose and are throttled; movement always yields to the existing combat, medical,
and territorial safety decisions. Paranoid and Militarized households allocate
extra watch behavior.

The household audits the recursively carried contents of its active residents,
with a depth-three and 512-item-per-resident ceiling. Food, water, medicine,
construction supplies, ammunition, and tools become qualitative Stable, Low,
Critical, or Well supplied statuses. No unloaded actor or world container is
silently invented.

One leader or fallback resident may approach the interior side of the primary
entry when a non-hostile visitor is nearby, outside, visible as a discovered
group, and not aiming. Wary Paranoid and Isolationist households stay inside.

## Crises and rumors

Supply collapse, illness, and internal dispute are rare deterministic checks
behind configurable cooldowns. Desperate groups are somewhat more vulnerable;
Resourceful groups are less vulnerable. Every crisis has a visible target or
resource and a bounded resolution/history record.

Each household owns three deterministic but deliberately imprecise reports. A
Tolerated or Trusted visitor can ask for one while near the representative.
Sharing writes a user-defined `[LF]` text symbol to `MapItem.getSingleton()`'s
`WorldMapSymbols`, then saves the world map. The reported coordinate is offset
from the household and carries an explicit report-day label; it is a lead, not
an oracle.

## Debug and verification

The debug-only Factions controls can select all six personalities, trigger each
crisis, resolve the current crisis, advance routines, force a resource audit,
and reveal the next rumor. Production builds expose none of these controls.

The Kahlua harness verifies personality selection, relationship generation,
all crisis transitions, nested-bag auditing, persistence, and the world-map API
contract. The disposable live sandbox verifies the same APIs against Build
42.20.4 Java objects and an isolated clone of the user's save. Static checks
ensure all controls remain in the private debug surface and all shipped UI text
is English.
