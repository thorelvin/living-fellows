PZOptimizer optional adapter — 0.27.0 development
2026-11-06

Implementation

SCPZOptimizerAdapter.lua activates at successful world startup and when the
player applies Options > Mods > PZOptimizer combat compatibility. It detects
native optimizer classes, not a Lua mod ID: loose overrides can be installed
without an enabled Workshop Lua entry. There is no polling or background scan.
World teardown disables the exception. The installed advice remains inert
when Off, and subsequent worlds reuse it without installing another hook.

SCPZOptimizerCompatibility validates the original class resources once, then
uses ZombieBuddy's public PatchEngine.applyPatches API. The patch package is
outside LF's automatically scanned bridge package and is installed only for
the validated optimizer build. Both submit overloads are probed before the
adapter reports active. Unvalidated bytes or a missing patch host produce an
unsupported diagnostic, not a global optimizer configuration change.

The advice returns false from ActionEval.submit only for a zombie targeting
an exact, currently owned SCNativeCompanion. This selects the caller's existing
inline postupdate path. Real players, other NPC mods, targetless zombies and
unowned/retired LF actors retain PZOptimizer's original method body. Nothing
changes native attack timing, wounds, health, visibility/player slots or saves.
The implementation neither adds damage nor modifies PZOptimizer's files.

Support includes adapter state, reason and cumulative intercepted submissions.
This is an optional bridge API extension; protocol 42.21-isocompanion-30 and
existing save schemas are retained. A mismatched older bridge is diagnosed.

Cause and earlier live controls

In the inspected optimizer, IsoGameCharacter.postUpdateAnimating defers action
evaluation through ActionEval.submit. IsoZombie.postUpdateInternal subsequently
recomputes canSeeTarget and clears targetSeenTime before the deferred graph
evaluates. Detached LF people are not normal visibility-slot players. Those
values are classified as pure callbacks, so the worker reads the cleared live
values. This can repeatedly restart the attack before its impact frame.

Earlier isolated 0.26.99, two-companion/three-zombie, 45-second passive controls:
- Defaults: 17 attack starts, zero successes/failures, zero completed clips,
  zero damage events and zero health loss. Run 20261106-155510-3ac5ec66.
- Animator parallelism Off alone: 23 starts, no completed attacks or damage.
  Run 20261106-154851-50311f38.
- Action evaluation parallelism Off alone: 27 successes, 18 damage events,
  7 completed clips, 160.67 combined health loss and one companion death.
  Run 20261106-155153-84aada31.
These controls establish the faulty pipeline; they predate the new adapter.
