Companion crowbar entry — 2026-11-13

Implementation
Right-click a locked, supported portal: Living Fellows > [name]: Force open
with crowbar. At camp the companion can borrow permitted stock; away from
camp a crowbar must be carried. One native attempt may contain several
struggles. After failure the order stops and exposes manual Retry.

Search expeditions can use a crew member's carried crowbar after ordinary
entry fails. Discovery stays inside the selected building's loaded vicinity,
visits at most 32 squares per slice, prefers doors, and excludes upper-floor
windows. The leader waits while the operator works. Failure does not escalate
to repeated forcing or axe bashing. Existing trip return limits still apply.

This is Lua only. No bridge, player-slot, camera, local-player flag, global
native action or vanilla game file is changed. Authored Strange Folk locks
and native security/jail exclusions remain protected.
