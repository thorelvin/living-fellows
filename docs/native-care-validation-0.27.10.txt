Native personal care - 0.27.10
Verified on Project Zomboid 42.22.2, 13 November 2026.

Changes
- Towel-assisted weather recovery uses stock ISDryMyself. Its incremental
  effects own wetness reduction, towel uses and the real wet-towel replacement.
  Replacement identity is observed, never created or replayed by LF. A staged
  towel or its actual wet replacement returns to its original carried bag.
- Automatic clothing and backpack changes use stock ISWearClothing. The stock
  complete() effect commits once within the existing logistics transaction.
  Only its player-backpack UI refresh is omitted for the NPC action instance.
  Exact item ownership, slot replacement and rollback remain verified.
- Removed obsolete, effect-free wash animation mappings. Body/shower washing,
  clothing washing, bandage cleaning and vehicle washing were already native.
- Explicit player Wear commands retain their immediate equipment behavior.
  No native bridge, player-slot flags, global action wrappers or background
  service changes are part of this conversion.
