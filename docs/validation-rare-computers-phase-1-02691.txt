Implemented
-----------
- Headerless CRT: silent first contact, a blinking prompt, native focused
  input off-screen, persona-coloured live input and typed replies. No BIOS,
  logo, caption, menu, close button, threat lamp or thinking spinner.
- Enter submits or skips; Up/Down history, page/wheel scrolling and Escape
  remain available. Digits do not auto-submit. Tab leaves chat alone.
- Live clock, calendar days, moodles, crew, deaths, threat, location and
  zombie facts; failed reads are omitted. Population/crew/history reads run
  on submission. The open window owns the existing 500ms threat watch.
  No persona background service or new event hook was added.
- Conversation progress, home position and effect receipts survive
  normalization. Unknown/broken persona extensions fall back to an ordinary
  word lock while preserving the computer. Non-finite saved seeds are
  repaired in the adapter, without changing the supplied engine.
- Physical drawer claim/release, exact native item receipts, supplied
  rewards and ordinary forced-entry contents. Previous-owner recipes cannot
  add water or nested items to persona rewards. A failed drawer release
  replaces the promised success with the supplied failure reply.
- Original deterministic LFSpiffyJingle.wav, 3.32 seconds, no samples.
  Native 3D playback and nominal 40-metre world sound, at most once/hour.
- Relief: stress -0.25 and unhappiness -20, once/game day. Cheer: boredom
  -25 once/game day. Weight: stress +0.05, capped at two/machine. These use
  the stat ranges verified in Phase 0; not every starting value crosses
  exactly one moodle tier. Receipts are committed before native effects.
- Power-cut reply and retained interruption flag. Shutdown waits for typing,
  releases a still-shut drawer, clears the lock, and uses factory reset to
  reopen ordinary EMMA. Power loss cancels a pending shutdown.
