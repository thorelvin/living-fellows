# Public-service and local-business terminal headers

27 October 2026, follow-up after `36259bff` was pushed to
`living_fellows/0.26.72`.

Six new transparent headers cover Meade County Police, West Point Town Hall,
Hobbs & Perkins Hardware, Ovo Farms, Lenny's Car Repair and Ekron Community
College. This brings the catalogue to 206 distinct identities. The Riverside
police flyer actually identifies Meade County Police, so the name is retained.
Town Hall, Ovo and college artwork are original terminal adaptations of the
verified names and visual references; they are not claimed as stock seals or
new canonical logos. No new owner stories or save schemas are added.

All six use inspected stock flyers and specific native advert rectangles in
`PrintMediaDefinitions`. Unknown offices, neighbouring properties, private
upstairs rooms and whole-mall adverts cannot borrow these identities. Existing
context-appropriate archive pools are reused. No world search runs per frame.

The headers retain their original colour families with bright main lettering:
sand for Meade County Police and Ovo, green for Hobbs & Perkins, and aqua for
Town Hall, Lenny's and Ekron. The global rare-purple draw still takes priority.
Assets have true alpha, transparent margins and no page backing. Prompt chains,
source hashes, file paths and alpha bounds are in
[the art manifest](terminal-community-art-manifest.json). All PNG copies retain
the generated bytes unchanged.

The metadata generator excludes these declared transparent assets from the
flat-background heuristic used for stock artwork. The first native review
showed that broad pale lettering on Hobbs & Perkins could otherwise be keyed
out as background. Regression checks now require no backing-removal key for
the new headers. Stock flat-backed artwork keeps its existing treatment.

Verification includes alpha/source audits, the terminal gameplay harnesses,
1,627 lore/branding checks and the complete UI suite. It covers each new site,
neighbour and private-home exclusion, context, colour, rare purple, source
crops and foreground preservation. Native preview fixtures reopen the clone's
actual powered computer for each header so logo, text, input and glass use the
same palette. Preview fixtures verify rendering; headless checks verify site
assignment. No valid taxi booking or expedition is launched.
