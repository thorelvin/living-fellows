Living Fellows: first-hour guidance
2026-11-07; feature/first-hour-guidance; based on 0.27.2 at 1d6dae6d
Runtime: Project Zomboid 42.21.0, single player. Release constants unchanged.

Implemented
First steps lives on Status, with a compact collapsed-launcher reminder. Real
recruitment, orders, camp, storage, job and computer events advance it. Talk now
offers Invite to join. Tips can be dismissed, disabled, reset and reread under
More > Support. Tip history is a bounded install-level file, not world save data.
Existing worlds skip the introductory checklist. Unused-feature hints remain
available, with danger suppression, grace periods and fifteen-minute spacing.
EMMA's first session offers a short introduction using commands that are valid
at that computer. No background building discovery or network service was added.

Fresh LF worlds get bounded retries for an independent survivor. The visitor
starts off-screen outdoors, approaches through normal navigation and calls once.
An additive, normalized firstMeeting bucket retains progress in schema 3. Missing
or invalid state cannot create endless retries. First arrivals get one sliced
30-metre clearing of hidden, idle ordinary zombies; later independent arrivals
get 8 metres. Visible enemies, active fights, foreign humans and corpse proxies
are excluded. There is no persistent clearing service or immunity.
