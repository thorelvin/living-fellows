Stair regression

The confirmed code regression entered in 6b274fb7, 6 November 2026 at
14:22:34 CET, as part of 0.27.0's window hardening. It is separate from
the uncommitted context-menu rebuild.

Native path telemetry supplies planar next-waypoint coordinates. The new
window check projected these onto the companion's current floor and could
take over a retained stair crossing for a window below its intended landing.
That takeover stopped native movement. A new case in the existing traversal
harness reproduced this before the fix (check 260).

SCNavigation._windowForNativeLease now defers planar window interception
while the companion is between floor heights or on a stair tread. Once on
a level landing, the existing checked-window policy still applies. This
does not enable routine window smashing or bypass landing safety checks.

The tester confirmed 0.27.0 and Rosewood. No new tester console was supplied,
so the exact reported route is not identified. The recorded 0.27.0 release
acceptance included one successful descent in about 14 seconds; that did
not establish reliability for every firehouse stair route or a group.
