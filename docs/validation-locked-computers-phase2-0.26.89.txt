Scope
-----
Phase 2 adds wheel, emma and search to the Phase 1 framework. It stops for the
user's next trial. Phase 3/4, public Field Guide publication, normal local game
installation, commits and pushes are not part of this checkpoint.
Version remains 0.26.89. No Java source or bridge protocol changed.

Implemented
-----------
UNDELETE.EXE restores all four actual owner files. Its corpus contains owners
of the same kind. Owner hits precede other owners; other-owner hits never count.
Index words have a guaranteed path through every one of the 162 owner profiles.
Queries run on input, use plain substring matching, reject short/stop words and
are limited to 32 characters. Indexes and result words are clickable. Three empty
queries give explicit guidance; eight expose the existing alternatives.

The Larchfield Owner's Manual is a real 0.3-weight ordinary item using vanilla
book models. It is placed once on a usable desk surface or free adjacent floor,
with the receipt marked before insertion. Missing/ambiguous insertion is never
replayed. Three challenges are required, or one when a handbook was already
carried at first settlement. Later possession does not rewrite an existing
three-challenge save. Nearby handbooks can be read from the CRT.

Five handbook pages include original illustrations. The last page draws two
live rings of upright letters, four alignment symbols and three clickable
windows. Arrows, mouse wheel and turn buttons operate the same rotation.
Compact windows retain numbered text controls. The fixed mapping is shared by
every computer and by the printable docs/larchfield-code-wheel.svg. The SVG is
one A4 page containing both cut-out discs, generated from the Lua constants.

Talk to EMMA uses four numbered arguments per round, five rounds at most,
4 conviction to win and two patience losses to fail. Claims read the actual
game clock, living recruited actors, Electrical skill, held screwdriver and
nearby threat facts. Changed truthful numeric records are updated for review;
the code does not silently rewrite a selected statement. No world scan runs
from the conversation renderer.

The supplied 30 arguments and all associated replies were copied unchanged.
Canonical SHA-256: f9e576bcf56f5713db22e47d50875b0d117fd210f47ad95f5485775d67171c9e
The user confirmed no repeated arguments within each attempt. An hour permits
a fresh attempt; a previously caught lie remains remembered. Saved offers do
not reroll on opening. Later visits quote the recorded false/true figures once
per session, at most three times. Factory reset clears this argument memory
while retaining the one-time XP receipt.

The Director includes only five built locks. Normal weights are 20/27/15/12/10,
normalized over those five, with the specified category boosts. The first tour
still begins Remembers, word, then a medium lock. New direct routes award
30 base Electrical XP; case/crack use the lower tier. Existing early/clutch
modifiers and mark-before-native-call protection remain shared.

Each new tool has an Electrical edge and a specific spoken companion hint.
Hints persist, respect the existing speech policy and never assign NPC work.
State remains an optional schema-one extension. Malformed argument choices
fall back conservatively; no missing handbook or cargo is manufactured.

Debug trial switch
-------------------
In an engine debug game set SCConfig.debugLockKind="wheel", "emma" or "search"
before the next newly settled locked computer. The setting is consumed once.
"word" and "remember" remain supported. It never rerolls existing settled
machines or bypasses physical power/access rules. Public default remains nil.
