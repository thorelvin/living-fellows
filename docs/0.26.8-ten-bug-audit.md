# 0.26.8 focused ten-bug audit

This pass audited the 0.26.7 Talk flow, command feedback, and a seating loop
reported in playtests. The numbered failures are distinct observable cases;
items 1, 2, and 8-9 share nearby code but have different triggers or effects.

| # | Failure in 0.26.7 | Correction | Verification |
|---|---|---|---|
| 1 | A pending Talk request lost to ongoing scavenging or boosted logistics and timed out without speech. | Give direct conversation priority over routine work while preserving emergency decisions. | Decision gameplay harness: scavenge hysteresis, logistics boost, emergency medicine. |
| 2 | A reply and its relationship effects could commit before the native movement stop accepted ownership. | Stop first; invoke the reply callback only after acceptance. | Positioning gameplay harness: rejected stop leaves the callback pending, accepted stop calls it once. |
| 3 | Talk remained enabled across floors although command dispatch rejected it. | Check the player and actor floor in availability. | Interaction UI harness: different-floor rejection. |
| 4 | A staged conversation continued when the player moved to another floor. | Cancel the staged approach when floors differ. | Positioning gameplay harness: cross-floor cancellation. |
| 5 | A staged conversation could chase a player beyond the 16-tile Talk limit. | Cancel the staged approach beyond 16 tiles. | Positioning gameplay harness: out-of-range cancellation. |
| 6 | A nearby neutral survivor had no direct right-click Talk shortcut. | Include registered neutral actors in the clicked Talk target set without granting them companion orders. | UI context contract test and source review of roster identity filtering. |
| 7 | An out-of-range conversation interruption could show a raw `%1` placeholder. | Supply the 16-tile argument to the translated reason. | Interaction UI harness: resolved distance reason. |
| 8 | A command service returning `nil` acceptance was shown as success and returned a truthy UI result. | Require `accepted == true` for command feedback, status opening, and callback result. | Source review and full UI gate. |
| 9 | A whistle or hand-sign service returning `nil` acceptance was shown as a successful signal. | Require `accepted == true` in the signal button. | Source review and full UI gate. |
| 10 | When one companion reserved the nearest seat, another could repeatedly choose that seat and fail instead of trying a free chair. | Skip live reservations held by other actors during furniture selection. | Gameplay furniture fixture: one actor holds the couch; another chooses the chair. |

The deterministic harnesses exercise the listed logic but cannot prove native
animation, actual right-click placement, or seat placement in a running game.
Use a disposable save for visual acceptance before a public Workshop upload.
