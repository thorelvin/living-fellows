# Living Fellows Field Manual

The GitHub Pages site for [Living Fellows](https://github.com/thorelvin/living-fellows): a player's guide to the mod, and a printable quick reference card.

**Release 0.27.8 · Project Zomboid 42.22.2.** Expeditions, Base Watch, Markus's taxi and EMMA lead the guide. This printing adds chicken and cattle care, collecting eggs and delivering milk, clearer relationship progress and direct gifts. EMMA's chapter covers follow-up questions, shared memories, caring conversations and a companion working the radio desk. Installation instructions now lead with the standalone edition, which needs no ZombieBuddy.
