# Living Fellows Field Manual

The GitHub Pages site for [Living Fellows](https://github.com/thorelvin/living-fellows): a player's guide to the mod, and a printable quick reference card.

**Release 0.26.67.** Expeditions, Base Watch and Markus's taxi lead the guide. Wood collection, camp jobs, equipment and home delivery are covered in their chapters.

- Field Manual: https://thorelvin.github.io/living-fellows/
- Quick Reference Card: https://thorelvin.github.io/living-fellows/quick-reference.html

Item icons, moodle icons and screenshots are linked from [PZwiki](https://pzwiki.net) rather than stored here; the game art they show belongs to The Indie Stone. Only Living Fellows project art is kept in `assets/`.
