# Living Fellows Field Manual

The GitHub Pages site for [Living Fellows](https://github.com/thorelvin/living-fellows): a player's guide to the mod, and a printable quick reference card.

**Release 0.27.10 · Project Zomboid 42.22.2.** A player's guide to expeditions, Base Watch, Markus's taxi, EMMA and life at camp. This printing explains how to care for chickens, cattle and sheep, mark milk barrels and manure storage, stock a Medic's kit and send a crew for fuel. Setup steps say what to prepare and where to look when work pauses. The quick reference covers the same features. Installation instructions lead with the standalone edition, which needs no ZombieBuddy.
