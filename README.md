# Living Fellows Field Manual

The GitHub Pages site for [Living Fellows](https://github.com/thorelvin/living-fellows): a player's guide to the mod, and a printable quick reference card.

**Release 0.26.87.** Expeditions, Base Watch, Markus's taxi and EMMA lead the guide. The illustrated computer chapter now covers building discovery, its radar and floor progress, saved equipment, pause/resume and read-only finds, with a real scanner image from Rosewood fire station. Questions, radio services, grid power, passwords, old files and factory reset are covered too. Map-selected destinations, storage and camp jobs have their own chapters.

- Field Manual: https://thorelvin.github.io/living-fellows/
- Quick Reference Card: https://thorelvin.github.io/living-fellows/quick-reference.html
- EMMA and camp computers: https://thorelvin.github.io/living-fellows/#emma

Item icons, moodle icons and general game plates are linked from [PZwiki](https://pzwiki.net); their game art belongs to The Indie Stone. `assets/` holds Living Fellows project art and credited in-game captures. The new scanner image is a lossless export of the native framebuffer, not a mockup. Any Project Zomboid business marks and world art shown in captures remain The Indie Stone's. Full credits are in the guide.
