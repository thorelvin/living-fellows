# Living Fellows Field Manual

The GitHub Pages site for [Living Fellows](https://github.com/thorelvin/living-fellows): a player's guide to the mod, and a printable quick reference card.

**Release 0.26.75.** Expeditions, Base Watch, Markus's taxi and EMMA lead the guide. The illustrated computer chapter covers questions, radio scanning, expeditions, building controls, passwords, old files and factory reset. Map-selected destinations, storage and camp jobs have their own chapters.

- Field Manual: https://thorelvin.github.io/living-fellows/
- Quick Reference Card: https://thorelvin.github.io/living-fellows/quick-reference.html
- EMMA and camp computers: https://thorelvin.github.io/living-fellows/#emma

Item icons, moodle icons and general game plates are linked from [PZwiki](https://pzwiki.net); their game art belongs to The Indie Stone. `assets/` holds Living Fellows project art and five actual in-game captures of its terminal UI. Any Project Zomboid business marks shown in those captures remain The Indie Stone's. Full credits are in the guide.
